## 📖 简介

Z-FindAll 是一款专业的 Windows 取证分析工具，集程序执行痕迹分析、安全日志审计、敏感文件扫描与计划任务风险评估于一体，专为数字取证、安全审计和系统运维人员设计。工具采用图形化界面，无需专业知识即可快速完成全量取证分析。

## ✨ 核心功能

### 🏠 首页导航

- 清晰说明 Prefetch 分析、安全日志、敏感目录、计划任务扫描、全文搜索的用途与方法

### 🔍 Prefetch 文件分析
- 自动读取 `C:\Windows\Prefetch` 目录下的所有 `.pf` 文件
- 解析程序执行信息：程序名称、运行次数、最近 8 次执行时间
- 提取关联文件路径：显示程序运行时访问的所有文件
- 支持自定义目录扫描
- **双击程序名**可查看完整详情（基本信息、执行时间、关联文件路径）
- **双击表头**支持按修改时间/文件大小排序
- 自动保存扫描结果为 JSON 缓存，支持**读取缓存**快速加载
<img width="1442" height="939" alt="image" src="https://github.com/user-attachments/assets/cc14e44b-8a0e-4128-8583-60b4a0e07c6e" />

### 🔐 安全日志分析
- 解析 Windows 安全事件日志（Security.evtx）
- 检测 RDP 远程登录事件（EID 4624/4625）
- 识别登录成功/失败记录
- 提取登录用户、来源 IP、登录时间等关键信息
- 自动保存扫描结果为 JSON 缓存，支持**读取缓存**快速加载
<img width="1442" height="939" alt="image" src="https://github.com/user-attachments/assets/0c6c1fb1-f7d8-449c-884d-9d57536bc84b" />

### ⚡ PowerShell 脚本块分析
- 解析 PowerShell Operational 日志（EID 4104）
- 提取所有脚本块执行记录
- 显示脚本执行时间、脚本长度
- **右键"查看脚本详情"**可查看完整脚本内容（深色代码高亮）
- 支持一键复制脚本内容
- 自动保存扫描结果为 JSON 缓存

### 📂 敏感目录扫描
- 扫描 `%TEMP%`、`%USERPROFILE%`、`C:\ProgramData` 等敏感目录
- 按时间范围筛选近期修改的文件（支持天/小时）
- **后台线程扫描**，不阻塞 GUI，支持实时查看扫描进度
- **取消按钮**可随时中断扫描
- 安全限制：最大 50000 个文件、超时 120 秒，防止资源耗尽
- **读取缓存**按钮可快速加载最近一次扫描结果
- **右键"打开文件位置"**可在资源管理器中定位文件
- 自动保存扫描结果为 JSON 缓存
<img width="1442" height="938" alt="image" src="https://github.com/user-attachments/assets/15cf9685-7480-4485-b903-d75d87843eb6" />

### 📋 计划任务扫描
- 通过 `schtasks` 全量枚举系统中所有 Windows 计划任务
- 解析任务名称、执行命令、运行账户、触发方式、调度规则等 **27 个全量字段**
- 兼容旧版 `.job` 任务发现
- **自动风险分析**：检测可疑路径、恶意程序特征、Base64 编码参数、隐藏窗口执行等 10+ 类风险指标
- 风险等级分级：信息 / 低风险 / 中风险 / 高风险 / 严重

- 支持分析报告 JSON 导出与缓存读取

## 🚀 使用说明

### 快速开始

1. **首页导航**
   - 程序启动后默认进入首页，浏览各功能模块介绍
   - 通过顶部工具栏切换至所需功能页面

2. **Prefetch 分析**
   - 点击"Prefetch分析"标签页
   - 点击"▶ 开始扫描"自动加载 `C:\Windows\Prefetch` 目录
   - 查看程序列表：程序名称 | 运行次数 | 最后运行时间
   - **双击程序名**查看完整详情
   - **双击表头**按修改时间或文件大小排序
   - 点击"📂 读取缓存"快速加载上次扫描结果

3. **安全日志分析**
   - 切换到"安全日志"标签页
   - 点击"▶ 开始扫描"解析 Security.evtx
   - 树形结构展示登录事件，展开节点查看详细信息
   - 点击"📂 读取缓存"快速加载上次扫描结果

4. **敏感目录扫描**
   - 切换到"敏感目录"标签页
   - 设置时间范围（天/小时），点击"▶ 开始扫描"
   - 扫描在后台执行，可实时查看进度
   - 点击"⏹ 取消"可随时中断扫描
   - 右键文件可选择"📂 打开文件位置"

5. **计划任务扫描**
   - 切换到"计划任务"标签页
   - 勾选"包含系统任务"可同时分析系统内置任务
   - 点击"▶ 开始扫描"枚举所有计划任务
   - 点击"🔴 风险分析"打开交互式风险报告，点击顶部风险级别按钮切换过滤
   - 双击列表或报告中的任务查看完整字段详情
   - 点击"📂 读取缓存"快速加载上次扫描结果

6. **全文搜索**
   - 切换到"搜索"标签页
   - 点击"🔄 刷新"加载所有缓存文件
   - 输入关键字后点击"🔍 搜索"或按回车
   - 使用来源过滤勾选框缩小搜索范围（支持计划任务数据源）
   - 右键搜索结果可查看详情/打开文件位置

### 右键菜单功能

| 页面 | 右键功能 |
|------|----------|
| Prefetch 列表 | 复制整行 / 复制单元格 |
| Prefetch 详情 | 复制此项 / 复制所有列 |
| 安全日志树 | 查看详情 / 复制此项 / 复制所有列 |
| 敏感目录 | 打开文件位置 / 复制整行 / 复制单元格 |
| 计划任务 | 查看详情 / 查看风险分析 |
| 搜索结果 | 根据来源类型：查看详情 / 打开文件位置 / 复制 |

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 在搜索框中触发搜索 |
| `F11` | 切换全屏 / 窗口模式 |
| `Ctrl+C` | 复制当前选中内容 |

### 数据导出

扫描结果自动保存为 JSON 格式，保存位置：
- **默认路径**：程序所在目录
- **文件格式**：
  - `prefetch_YYYYMMDD_HHMMSS.json` — Prefetch 扫描结果
  - `seclog_YYYYMMDD_HHMMSS.json` — 安全日志扫描结果
  - `ps4104_YYYYMMDD_HHMMSS.json` — PowerShell 脚本块结果
  - `scandir_YYYYMMDD_HHMMSS.json` — 敏感目录扫描结果
  - `taskscan_YYYYMMDD_HHMMSS.json` — 计划任务扫描结果
  - `task_report_YYYYMMDD_HHMMSS.json` — 计划任务风险分析报告

## 🎯 应用场景

### 数字取证
- 调查可疑程序的执行历史
- 追踪恶意软件的活动轨迹
- 分析用户操作时间线
- 检查敏感目录中的可疑文件

### 安全审计
- 检测异常登录行为
- 审计 RDP 远程访问记录
- 排查暴力破解尝试
- 审查 PowerShell 脚本执行记录

### 系统运维
- 统计常用程序使用情况
- 清理长期未运行的程序
- 优化系统启动项
- 监控敏感目录文件变化

## ⚠️ 注意事项

1. **管理员权限**：程序需要管理员权限才能访问系统日志和 Prefetch 目录
2. **数据隐私**：本工具仅读取本地数据，不会上传任何信息
3. **兼容性**：仅支持 Windows 系统，不支持 macOS/Linux
4. **日志文件**：安全日志默认位于 `C:\Windows\System32\winevt\Logs\Security.evtx`
5. **扫描性能**：敏感目录扫描在后台线程执行，大目录可能需要较长时间，可随时取消

## 🐛 常见问题

### Q: 提示"拒绝访问"？
A: 右键点击 EXE，选择"以管理员身份运行"

### Q: Prefetch 目录为空？
A: 检查系统是否启用了 Prefetch 功能（某些 SSD 优化可能禁用）

### Q: 窗口显示不完整？
A: 窗口最小尺寸为 1440x900，如需更大显示区域可拖拽边框放大、点击最大化或按 F11 进入全屏模式

### Q: 安全日志扫描很慢？
A: 安全日志文件可能很大（数百MB），解析需要 1-2 分钟，请耐心等待

### Q: 敏感目录扫描卡住？
A: 点击"⏹ 取消"按钮中断扫描，或缩小时间范围后重试

### Q: 如何反馈问题？
A: 在 GitHub 仓库提交 [Issue](https://github.com/Rt8848666/Z-FindAll/issues)
